## ♜ Cardkeep — Card Tower Defense

A self-contained, wave-based tower defense game. Spend gold on four defense cards
(Watchtower, Ironmouth, Frostwitch, Sun Shrine), place them beside the old road,
and hold Ashenwood Crossing for eight waves.

**Run it**

```bash
python3 -m http.server 3002
```

Then open <http://localhost:3002>.

**Controls**

- Click a card (or press `1`–`4`) to select a defense.
- Click an empty tile to place it. You can build before or during a wave.
- `Space` starts the next wave or pauses during combat.
- Use the `1× / 2×` button to change battle speed.
- At the end screen, choose **Defend Again** (or press `R`) to restart.

No build step or dependencies are required.
